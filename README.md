# Archivebate Scraper
![image](https://github.com/Temp530/Archivebate-Scraper/assets/129143010/0e4b6d3c-bc9d-41de-b02d-593d8948a855)  
Scrapes over plain HTTP (no Chrome or chromedriver needed).  
  
`Page Counter`: How many profile pages are fetched at the same time.  
  
`URL Scrapper`: How many video pages are checked at the same time.  
  
`Success` list: URL, file size and upload date of each video, with the total size below.  
Ctrl+C copies the selected URLs (all URLs when nothing is selected), Ctrl+A selects all.
